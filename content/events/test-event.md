## Difference in time stamps

There seems to be an issue with the timestamps. When using the CMS the slightly changed format seems to stop publication of a post. When changed to the Hugo one this goes away.

```yaml
date: 2024-04-22T10:28:17+01:00 # Hugo version that works
date: 2024-04-22T10:41:00.000Z # Does not publish
```


So it appears to be the date stamp in the front matter which generated from the CMS is different from that generated by Hugo. And it only seems to work with Hugo's timestamp..

EXCEPT there are some other events where the CMS timestamp format does work...
